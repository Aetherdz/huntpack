# Changelog

All notable changes to HuntPack are documented here.

## [1.0.0] — 2026
### Added
- Initial public release.
- 12 skills across a 6-stage hunting pipeline:
  - `bb-methodology` — master conductor
  - `application-archetypes`, `application-model-builder` — understand the target
  - `web2-recon` — map the surface
  - `web2-vuln-classes`, `business-logic-hunter`, `api-security` — hunt
  - `domain-scoped-hunting` — discipline / anti-fabrication
  - `false-positive-killer`, `triage-validation` — prove findings
  - `attack-path-builder`, `report-writing` — deliver value
- Full README, MIT license, contributing guide, safety policy.
